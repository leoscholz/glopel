# Glopel

Ferramentas da consultoria/automação da Glopel (Embalagens Globo).

| Pasta | O que é |
|---|---|
| [`espelho/`](espelho/) | **Espelho do Start** — cópia de leitura das telas do sistema (Pedidos de Venda, Contas a Receber, janela de Lançar Recebimento). Nada grava. **Dados de exemplo**; os reais ficam privados ou entram por *Espelho › Carregar dados…* (só no navegador). |
| [`mesa/`](mesa/) | **Mesa da Glopel** — réplica 3D clicável da mesa física. Cada objeto (monitor, pedidos, notas fiscais, caixa da Daiane, gavetas, LEADS…) abre os papéis que moram ali. Papéis de exemplo. |

Site (GitHub Pages): https://leoscholz.github.io/glopel/mesa/

Espelho: https://leoscholz.github.io/glopel/espelho/
