# Glopel

Ferramentas da consultoria/automação da Glopel (Embalagens Globo).

| Pasta | O que é |
|---|---|
| [`sistema/`](sistema/) | **Sistema Globo (α 0.1)** — protótipo do sistema que vai substituir o Sage Start. Menu completo (Pedidos, Clientes, Produção, Bobinas, Fornecedores, Financeiro, Artes, Produtos, Fiscal); só **Bobinas** funciona: estoque por tipo, consumo, quando pedir, pedidos em trânsito e contagem. **Dados de exemplo**; os reais entram por *Carregar planilha (.xlsx)* (só no navegador). |
| [`espelho/`](espelho/) | **Espelho do Start** — cópia de leitura das telas do sistema (Pedidos de Venda, Contas a Receber, janela de Lançar Recebimento). Nada grava. **Dados de exemplo**; os reais ficam privados ou entram por *Espelho › Carregar dados…* (só no navegador). |
| [`editor-sacolas/`](editor-sacolas/) | **GloboEditor (α 0.1)** — loja de demonstração + editor de arte para as facas OHDE (1/2, 1, 3, 5, 10 kg, Hamburgão; kraft e branco). Prévia, chapas por Pantone, mockup 3D, retícula. *Pedir ao Claude* desativado nesta versão. Salva só no navegador. |
| [`whatsapp/`](whatsapp/) | **Globo no WhatsApp** — protótipo clicável da conversa de pedidos: Meus produtos, repetir pedido, arte nova pelo GloboEditor, Pix, prova da clicheria e status. Roteiro editável. Dados e Pix ilustrativos. |
| [`mesa/`](mesa/) | **Mesa da Glopel** — réplica 3D clicável da mesa física. Cada objeto (monitor, pedidos, notas fiscais, caixa da Daiane, gavetas, LEADS…) abre os papéis que moram ali. Papéis de exemplo. |
